# v1.20.7

## Fix — vector false-positive + booster dist-tag

### Vector “HNSW ready” ảo
- **Root cause:** `@sparkleideas/memory@3.0.0-alpha` (npm latest `3.0.0-alpha.11-patch.30`) export classes (`UnifiedMemoryService`, `HNSWIndex`…) không còn facade `{init,add,search}` mà Hive gọi. Hive gán nguyên namespace làm instance, báo “HNSW ready”, nhưng mỗi `add`/`search` ném lỗi và lặng lẽ rơi về text-mode. Bản thay thế `3.5.2-patch.1` thì tarball thiếu `dist/` nên `require` cũng fail. → Chưa có bản memory nào trên npm tương thích.
- **Fix:** `src/services/vector-memory.ts` thêm `hasFacade()` check (`add` && `search`) trước khi gán `memoryInstance`; nếu không có facade → throw với message rõ (`need add/search, found UnifiedMemoryService...`) → `catch` đặt `memoryInstance=null` và báo fallback. Status giờ trung thực (fallback, không còn “ready” ảo) — text-search với sharding/quality vẫn persist bình thường.

### Booster `latest` trỏ nhầm
- **Root cause:** `npm view @sparkleideas/agent-booster dist-tags` → `latest: 0.2.2-patch.32` (dòng cũ), trong khi `0.2.34` mới là bản có thật trên registry và Hive cần `^0.2.34`. `npm install @sparkleideas/agent-booster` (không version) sẽ kéo `0.2.2-patch.32` cũ → `hive_booster_status` `available:false`.
- **Fix:** `src/utils/tool-installer.ts` thêm `ToolEntry.version`, pin `agent-booster@0.2.34`, `isModuleResolvable(name, version)` kiểm tra `package.json` version, `ensureToolsInstalled` cài `name@version`, check cả hive + global + `require.resolve` version-aware.

### Verify
- `bun run build` OK (141 modules), `bun test` 595 pass.
- Sau cài `agent-booster@0.2.34` thủ công + 1 restart MCP, `hive_booster_status` → `available:true`.
