# v2.0.2 — V1 agent parity + v2.1 compatibility fixes

Bản **2.0.2** đưa hành vi agent về giống v1 (`build`/`plan` không còn là primary), bỏ field `temperature` mà OpenCode 2.1 không hỗ trợ, và sửa ba lỗi nhỏ phát hiện khi test live.

## Sửa

### 1. `build`/`plan` được hạ về subagent (giống v1)

- Plugin gọi `agentEditor.update("build" | "plan", …)` để đặt `mode = "subagent"` sau khi reload catalog agent.
- `zetta` là agent primary duy nhất hiện trong bộ chuyển agent; `agentEditor.default("zetta")` vẫn giữ nguyên.
- **Không** hạ `compaction`, `title`, `summary` — đây là agent hệ thống ẩn, `opencode run` dùng nội bộ; hạ chúng từng làm mọi session lỗi `AgentNotFoundError`.
- Comment trong `agent-mode.test.ts` (nói demote làm vỡ `opencode run`) đã lỗi thời và được thay bằng test khẳng định đúng hành vi mới.

### 2. Không còn warning `temperature`

- OpenCode 2.1 bỏ field `temperature` khỏi agent definition/config; mọi file `.opencode/agents/*.md` do plugin sinh ra đều bị log
  `WARN ignored unsupported agent fields path=.../zetta.md fields="[\"temperature\"]"`.
- Plugin thôi ghi field này. `temperature` trong `agent_hive.json` vẫn được parse (không phá config cũ) nhưng OpenCode bỏ qua — đã ghi rõ trong README.

### 3. `hive_tasks_sync` không còn im lặng khi plan sai định dạng

- Nếu plan có `## Tasks` nhưng không có header `### <số>. <Tên task>`, kết quả trả thêm cảnh báo kèm ví dụ header đúng, thay vì chỉ `Tasks synced: 0 created, 0 removed, 0 kept`.

### 4. Commit lại được sau lần "No changes to commit"

- `hive_worktree_commit` trước đây vẫn đánh dấu task `done` khi không có thay đổi; lần commit sau bị từ chối `invalid_task_state` dù worktree đã có file mới.
- Nay nếu task đã `done` nhưng branch **chưa có commit nào** so với `baseCommit`, lần commit sau được chấp nhận và commit bình thường.

### 5. `verificationNote` nhận dòng `Verification:`

- Danh sách keyword kiểm tra evidence có thêm `verification`/`verify`, nên summary ghi `Verification: ...` không còn bị báo thiếu evidence.
