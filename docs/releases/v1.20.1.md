# v1.20.1

## Fixes

### Self-test 4 bugs (v1.19.0 report)
- **ast-grep `extensions` crash** — `ast_grep_find_code / scan_code / analyze_imports / rewrite_code` gọi `args.extensions.split` khi param optional bị omit → fallback `".ts,.tsx,.js,.jsx"` + safe defaults cho `path`, `lang`, `maxResults`, `dryRun`, `maxDepth`.
- **ast-grep rewrite metavariable** — `match.replace()` của `@ast-grep/napi` trả về `insertedText` literal (không expand `$MSG`), fix bằng `substituteRewrite()` hỗ trợ `$NAME` (`getMatch`) và `$$$NAME` (slice theo range để giữ spacing).
- **typed-memory unreachable** — `hive_memory_update` chỉ update → đổi thành **upsert** (tạo mới nếu không có match), thêm tool mới `hive_memory_create` (scope/type/content/issue/tags), fix regex parse escaped quote `content="((?:[^\"\\]|\\.)*)"` và hint recall trỏ đúng tool.
- **auto-cr-cmd bin name** — package publish bin là `check` không phải `auto-cr-cmd` → `resolveAutoCrBinary()` thử `auto-cr-cmd` → `check` → `~/.config/opencode/hive/bin/*` → `npx`, probe bằng `--help` (không có `--version`), đọc version từ `package.json`, installer alias cả 2 tên.

### Chore
- **Remove dora** — xóa `src/tools/dora.ts`, 6 tools `dora_*`, installer entry `@butttons/dora`, `peerDependenciesMeta`, `model-selector` categories, update prompts (`codebase-locator/analyzer/pattern-finder`) sang `grep` + `lsp_*`, stub `doraSymbolSearch` trong `code-search.ts` (không còn `execSync('dora')`).
