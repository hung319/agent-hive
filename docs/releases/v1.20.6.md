# v1.20.6

## Fix — upstream TS7 + global resolve

### LSP: TypeScript 7.0.2 Go port breaks language-server 6.x
- **Root cause:** Hive pin `typescript@latest` → 7.0.2 native Go (cấu trúc module khác) không tương thích `typescript-language-server@6.x` → handshake fail → `lsp_diagnostics`/`hover` báo `ready` nhưng `success:false`.
- **Fix:** `lsp/registry.ts` pin `typescript@^5` (thay vì `typescript` latest), `services/lsp-autoinstall.ts` thêm auto-downgrade: nếu `~/.config/opencode/hive/lsp/node_modules/typescript/package.json` version `7.*` → `npm install --prefix <lsp> typescript@5.9.3`. Người dùng đã workaround `npm install typescript@5` sẽ giữ nguyên; lần cài lại tới sẽ không lên 7 nữa.

### Vector/booster: không nhặt global `@sparkleideas/*`
- **Root cause:** `vector-memory` chỉ `hivePkgPath ? require(hive) : require('@sparkleideas/memory')` (hive-only), `tool-installer.getGlobalNpmRoot` chỉ `npm root -g`. Nếu user cài global qua `bun`/`pnpm` hoặc Hive chưa bundle, → fallback text-mode / native edit.
- **Fix:** `tool-installer` thử `npm root -g` + `bun pm bin -g` + `pnpm root -g` + `~/.bun/install/global/node_modules`; `vector-memory` cũng check `globalRoot/@sparkleideas/memory` trước khi `require('@sparkleideas/memory')`.

### Chore
- `tool-installer` tự xóa stale `bin/dora` (còn sót sau khi xóa dora ở 1.20.1) khi `ensureToolsInstalled` chạy lần tới; `btca` giữ lại (vẫn trong `TOOLS`).
