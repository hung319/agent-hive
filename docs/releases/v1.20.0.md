# v1.20.0

## Features

### Replace snip with RTK 🚀
- **RTK binary** replaces the old snip binary — 76k stars, 100+ command filters, built-in analytics for token reduction
- Updated config types from `snip` to `rtk`

### New Skills
- **ponytail** — lazy senior dev philosophy with decision ladder
- **caveman** — terse output mode with 3 levels
- **skill-creator** — guide for creating new Hive skills

### New MCP & Tools
- **codegraph MCP** — SCIP-based code analysis (symbols, references, cycles)
- **gitingest native tool** — repository analysis directly in chat
- **codegraph-init** — automatic workspace indexing on plugin load

### Removed
- Old snip installer and repomix MCP replaced by RTK + codegraph stack

## Internal

- Test suite stability fixes — bun test reduced from 65s to ~10s
- e2e git ops isolation hardened against `child_process` mock leakage
- LSP test isolation fixed to prevent cross-file vi.mock leaks
- Improved error messages on git revparse failures in CI
