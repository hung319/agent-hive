## v1.21.2 - Fix CodeGraph MCP Connection Error

### Bug Fixes

- **CodeGraph MCP**: Fixed `MCP error -32000: Connection closed` when running inside OpenCode
  - Root cause: `process.execPath` returns the OpenCode binary (Bun) instead of Node.js
  - Fix: Added `isNodeBinary()` check and `findNodeBinary()` fallback to locate real Node.js
  - Fallback chain: npm-shim (with real node) → managed bundle → PATH executable
