# v1.21.1

## Feat — Codegraph MCP không cần restart

### Vấn đề
- Ở 1.21.0, MCP `codegraph` chỉ được đăng ký khi binary đã cài xong; binary được tải ngầm ở boot promise → user phải **khởi động lại opencode một lần** trước khi dùng được. oh-my-openagent làm được với 0 lần restart.

### Fix — kiến trúc npm-shim
- Thêm dependency [`@colbymchenry/codegraph`](https://www.npmjs.com/package/@colbymchenry/codegraph): package có bin shim (`npm-shim.js`, CJS thuần) tự định vị platform bundle trong `optionalDependencies` (esbuild os/cpu pattern) và **tự tải từ GitHub Releases lúc spawn nếu thiếu** (self-heal, mirror-safe).
- MCP được đăng ký với `[process.execPath, npm-shim.js, 'serve', '--mcp']` — session đầu tiên đã dùng được; chỉ kết nối MCP đó chờ download lần đầu, không block app.
- Fallback giữ nguyên cho môi trường đặc biệt: bundle marker cũ (`~/.config/opencode/hive/codegraph/current.json`) → executable trên PATH.
- Bỏ env `CODEGRAPH_NO_DOWNLOAD` để shim tự heal hoạt động.

### Refactor
- Xóa bộ downloader/TTL 24h/checksum map tự viết + module `codegraph-version.ts` (~600 dòng net): hết dual-install giữa hive-dir và cache của shim. Binary giờ update theo bản release plugin (bump dependency).
- Boot plugin không còn gọi network cho codegraph — chỉ chạy `init`/`sync` project bằng argv đã resolve (`string | string[]`).

### Verify
- `bun run test`: 623 pass / 0 fail.
- `tsc --noEmit`: không phát sinh lỗi mới; bundle build OK với `--external @colbymchenry/codegraph`.
- E2E: resolver trả nguồn `npm` → shim chạy ra `1.5.0`; `getBuiltinMcps()` đăng ký đủ command ngay cả khi chưa từng cài binary.
- CI: green trên ubuntu-latest.
