# v1.21.0

## Feat — Codegraph MCP tự động cài + tự động cập nhật

### Vấn đề
- `plugin.json` đăng ký MCP `codegraph` chạy `codegraph serve --mcp` nhưng **không có gì cài binary** → opencode spawn thất bại `ENOENT`, MCP đỏ ngay từ lần khởi động đầu.
- `codegraph-init.ts` chỉ check PATH rồi skip; comment "Auto-provisions" sai sự thật. Template `templates/mcp-servers.json` lệch với plugin (thiếu codegraph).

### Fix — auto-provisioning
- **Installer mới** (`src/utils/codegraph-installer.ts` + `codegraph-version.ts`): tải self-contained bundle (kèm Node runtime, không cần system Node) từ GitHub Releases của [`colbymchenry/codegraph`](https://github.com/colbymchenry/codegraph), verify SHA256 theo file `SHA256SUMS` của cùng release trước khi install. Layout: `~/.config/opencode/hive/codegraph/<ver>/` + marker `current.json` (không dùng symlink — tránh vấn đề quyền Windows).
- **Auto-update mode**: resolve bản latest qua redirect `releases/latest` (không gọi api.github.com — rate limit 60 req/h trả 403 trên shared host), re-check tối đa 1 lần/ngày (TTL 24h trong marker `lastCheckedAt`). Có bản mới → tải ngầm, swap, sweep version dir cũ (~280MB/bundle). Offline/resolve fail → giữ nguyên bản hiện tại.
- **Đăng ký có điều kiện**: `mcp/index.ts` chỉ đưa codegraph vào config khi binary available, dùng absolute launcher path → hết MCP đỏ ENOENT. Install chạy background ở boot promise — session kế tiếp sẽ thấy MCP.
- **Boot chain**: `src/index.ts` wire install xong → tự `codegraph init`/`sync` cho project bằng đúng binary vừa resolve (trước đây fire-and-forget nuốt lỗi).

### Fix — CI
- Bun trên runner: shell-string `execSync('tar xzf …')` báo `command not found` trong khi `execFileSync('tar', [...])` cùng binary chạy OK → extract qua argv-array.
- Bun snapshot env lúc startup — child process không thấy runtime PATH mutation → `isCodegraphOnPath` scan PATH trực tiếp bằng JS (tiết kiệm 1 fork mỗi lần check).
- Test bỏ hoàn toàn spy `child_process` — điều khiển availability qua PATH thật + shim executable.
