# v1.20.2

## Fixes

### auto_cr_scan path dropped (regression 1.20.1)
- `auto_cr_scan` gọi `check --language en --output json <path>` nhưng wrapper cũ đặt `--output json` sau path (`--language en <path> --output json`) và không quote path có space, khiến CLI báo thiếu path (tiếng Trung) và scan 0 file. Fix: đổi `execute({path, language})` → `scanTarget ?? './src'`/`language ?? 'en'`, gọi `runAutoCr(['--language', language, '--output', 'json', scanTarget])` (path luôn last), `runAutoCr` tránh duplicate `--output` và quote args chứa space.

### LSP detection luôn reinstall
- `lsp-autoinstall` và `lsp-manager` đều check `~/.config/opencode/hive/lsp/bin/typescript-language-server` nhưng `npm --prefix` cài vào `node_modules/.bin/...`, nên `isInstalled` luôn false → reinstall vòng lặp với log `Tried: npm and npm`. Fix: checkCommand đổi sang `node_modules/.bin/...` (TypeScript, @volar, volar, svelte), `prependLspToPath` prepend cả `node_modules/.bin` + legacy `bin`.

### Minor
- Vector `fallback:true` vẫn hiện dù HNSW ready — không ảnh hưởng search, để lại cho lần sau (cần làm rõ trạng thái file-fallback vs vector backend).
